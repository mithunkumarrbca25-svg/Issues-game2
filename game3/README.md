# Game 3 — Race Against the Commit 2

This is the final contribution challenge.

The organizer will release a new `final_clue.txt` file when the final round begins.

## Your task

1. Watch the repository's commit history.
2. Find the new `final_clue.txt` commit.
3. Read the clue.
4. Solve the clue using the secret word provided by the organizer at the event venue.
5. Create a file named exactly `final-answer.txt` in your own fork or working repository.
6. Put your solved answer inside that file.
7. Commit and push the file.
8. Return to the Game 3 issue and comment using:

```text
/answer <your solved answer>
Commit: <link to your commit>
```

You may open the Game 3 issue directly, but submissions are accepted only after Game 2 has been completed successfully.

The organizer will manually verify the contents of `final-answer.txt`.
